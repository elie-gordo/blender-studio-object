## Titre
**TENSIL — lampe articulée en studio**

## Accroche
Une lampe à ressorts imaginée, modélisée, éclairée et animée entièrement par scripts Blender, en duo humain + IA.

## Texte de la page projet
> TENSIL est une lampe de bureau articulée d'une marque fictive, conçue pour ce projet. J'ai défini le concept, le style packshot studio, le coloris graphite et laiton et l'animation ; Claude (IA d'Anthropic) a produit la 3D en écrivant des scripts Python pour Blender 5.2, que j'ai validés étape par étape.
>
> Le projet couvre toute la chaîne d'un visuel produit : modélisation mécanique, rig dont les ressorts suivent les articulations, matériaux PBR sans texture, éclairage studio, quatre rendus Cycles, une animation de 8 s (dépliement puis allumage) et un modèle GLB compressé de 203 Ko pour le web. Toute la scène se reconstruit en une commande. Coût : 0 €.
